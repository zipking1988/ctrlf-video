DESKTOP ALPHA

A question. A moment. A finding.

Use CtrlF Video to investigate what is visible in one recording. Start with the recorded example to try the complete review workflow without an account or a model request.

  1. Choose your recording

    Try the real example, explore the preset demo, or upload an authorized video. Upload checks the file and enables playback; it does not start AI analysis.

  2. Ask a visual question

    For an approved session, use Menu → Sources → Start analysis first. Ask one concrete question, such as “Where does an error message appear?” Enter sends; Shift+Enter adds a line. If live questions are off, keep a draft or open a saved answer.

  3. Replay the evidence

    Click a timestamp to seek the source. Timeline shows the selected answer’s cited frames. Replay the surrounding footage and check unresolved claims in Still to verify.

  4. Write and export a finding

    Choose Details & save → Write a finding. Separate observed facts from interpretation and open questions. Save, then use Menu → Export report for Markdown, JSON or HTML. The recorded example has its own Export report button below the finding.

What this alpha can and cannot tell you

Gemini reviews sampled images, so brief events and small text can be missed. Timeline is a citation list, not a complete video breakdown. Audio is not transcribed. The basketball example is a saved real partial result; the package demo uses synthetic preset answers. Neither establishes quality on UX studies.

Privacy, saving and recovery

Uploaded recordings stay on the server. Approved analysis sends sampled JPEGs and text to Google Gemini. Private access belongs to this browser’s session cookie; there is no account or cross-device recovery. Retention defaults to 24 hours; the upload screen shows the configured period. Delete recordings through Sources.

Workspace edits save automatically. If saving fails or another window changes the investigation, keep this page open and use the save indicator to recover. Export a copy before expiry or clearing cookies. Private video links still require your session; HTML can embed evidence images for a portable report. Example findings save only in this browser.

Prepare model analysis
  1. Use Gemini docs/runtime.example.json, to prepare private local configuration. Template placeholders are not runnable.
  2. Gemini Explicitly permit locally decoded sample JPEG frames to be sent to Google; Audio transcription is not supported. Keep credentials in server environment variables.
  3. Define finite spending and call limits, calibrate costs and resource cutoffs, then have the local operator record both budget approvals.
  4. Set CTRLF_RUNTIME_FILE and CTRLF_VIDEO_MODE=real, then restart and check again. Sources applies admission limits using the actual window count.
